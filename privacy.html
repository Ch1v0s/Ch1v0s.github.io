EDITH Privacy Policy

Last updated: November 5, 2026

EDITH is a personal assistant that runs on its owner's own computer and is used only by its owner. This policy explains how it handles Google user data.

Data EDITH accesses

With the owner's consent through Google sign-in, EDITH can:

  • Read Gmail messages (gmail.readonly) to search and summarize the owner's email.
  • Send email (gmail.send), only after the owner approves each message in an on-screen dialog.
  • Read and create Google Calendar events (calendar.events); new events are created only after the owner approves each one.

How the data is used

Google data is used only to answer the owner's own requests. It is processed on the owner's computer by a locally running AI model. It is not sent to third-party AI services, and it is not used to train AI models.

Storage and security

The Google sign-in credentials are stored in the macOS Keychain on the owner's computer. Email contents are not written to logs. Nothing is stored on any external server operated by EDITH.

Sharing

Google user data is never sold, shared with, or transferred to anyone else, and is not used for advertising.

Limited Use

EDITH's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be sent to the support email listed on the app's Google sign-in screen.
